🏦 Sistema Bancário em Java
📌 Sobre o projeto

Projeto de um sistema bancário desenvolvido em Java, executado através do terminal.

O objetivo foi colocar em prática conceitos fundamentais de programação, como entrada de dados, variáveis, estruturas condicionais, laços de repetição e operações matemáticas.

⚙️ Funcionalidades

O sistema permite:

💰 Consultar o saldo atual;
💵 Receber valores;
💸 Transferir valores;
⚠️ Verificar se existe saldo suficiente para realizar uma transferência;
🚪 Encerrar o sistema.
🖥️ Menu do sistema
1 - Consultar saldos
2 - Receber valor
3 - Transferir valor
4 - Sair
🛠️ Tecnologias utilizadas
Java
IntelliJ IDEA
Git
GitHub
📚 Conceitos praticados
Variáveis e tipos de dados;
Scanner para entrada de dados;
Estruturas condicionais (if, else if e else);
Laço de repetição while;
Operadores matemáticos;
printf para formatação de valores;
Text Blocks e .formatted().
🚀 Como executar
Pré-requisitos

É necessário ter o Java JDK instalado no computador.

Execução

Clone o repositório:

git clone URL_DO_REPOSITORIO

Entre na pasta do projeto:

cd BancoC

Compile o programa:

javac Main.java

Execute:

java Main
